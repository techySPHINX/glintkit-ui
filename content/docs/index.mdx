**GlintKit UI** is a cutting-edge React component library built atop **Radix UI**, **Tailwind CSS**, and **Framer Motion**.  
It’s designed for **speed**, **flexibility**, and an exceptional **developer experience**.

---

## ✨ Why GlintKit UI?

- 🧑‍🎨 **Modern & Beautiful**: Crafted for today’s web with thoughtfully designed, accessible components.
- 🧱 **Radix UI Primitives**: Built on battle-tested accessibility and composability foundations.
- 🎨 **Tailwind CSS Theming**: Effortlessly customizable to match your brand or product.
- 🎞️ **Framer Motion Animations**: Delightful, performant transitions out of the box.
- 🧑‍💻 **Developer-First**: TypeScript support, composable APIs, and clear documentation.
- 🏗️ **Scalable**: Perfect for design systems, dashboards, SaaS products, and web apps.

---

## 🚀 Get Started

Install GlintKit UI and its peer dependencies:

```bash
npm install glintkit-ui radix-ui tailwindcss framer-motion
```

## 🌈 Make it Yours

- **Customizable**  
  Use Tailwind’s theming for instant brand alignment.

- **Animated**  
  Framer Motion brings micro-interactions to life.

- **Accessible**  
  Built-in a11y best practices.
